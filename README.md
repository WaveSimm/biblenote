# BibleNote — 성경 읽기·비교 앱 (v1)

7개 번역본(개역개정·공동번역·표준새번역·현대어성경·NIV·NASB·메시지)을 읽고 비교하는 개인용 성경 앱입니다.

## 실행 방법 (PC)

1. 이 폴더에서 `serve.bat`를 더블클릭 (Python이 설치되어 있어야 합니다)
2. 브라우저에서 `http://localhost:8080` 접속

Python이 없다면 설치: https://www.python.org/downloads/ (설치 시 "Add to PATH" 체크)

## 스마트폰에서 보기

1. PC에서 `serve.bat` 실행 상태 유지
2. 폰을 **같은 와이파이**에 연결
3. PC의 IP 확인 (명령 프롬프트에서 `ipconfig` → IPv4 주소, 예: 192.168.0.5)
4. 폰 브라우저에서 `http://192.168.0.5:8080` 접속
5. 메뉴 → **"홈 화면에 추가"** 하면 앱처럼 설치됨

> 항상 폰에서 쓰려면 GitHub Pages 같은 무료 호스팅에 올리는 것을 권장합니다
> (폴더 전체를 업로드하면 끝 — 원하시면 다음 단계에서 같이 설정).
> 한 번 접속해 둔 뒤에는 오프라인에서도 동작합니다(PWA).

## 사용법

- **상단**: 번역본 칩(탭하면 즐겨찾기 4종 중 선택) · 현재 위치 · ⇆ 비교 모드 전환
- **하단**: ◀ ▶ 히스토리 이동 · 🔍 권장절 검색 · ☰ 책/장 선택 · Aa 보기 설정
- **검색 예**: `요3:16` `창세기 1:1` `롬 8` `살전 5` `John 3:16`
- 본문을 탭하면 상/하단 바가 숨겨지고 전체 화면으로 읽을 수 있습니다
- 절은 이어쓰기, 장은 줄바꿈만(여백의 옅은 숫자가 장 번호), 스크롤은 책 전체가 끊김 없이 이어집니다
- 마지막 읽던 위치·번역본 구성은 자동 저장되어 다음에 열 때 복원됩니다

## 폴더 구조

```
index.html          앱 진입점
css/app.css         스타일 (테마·조판)
js/main.js          리더·UI (연속 스크롤, 비교 동기화, 히스토리)
js/data.js          본문 데이터 공급 (BibleRepository)
js/parser.js        권장절 검색 파서
js/store.js         설정·히스토리 저장
data/books.json     66권 메타 (이름·약어·장절 수)
data/versions.json  번역본 목록
data/{code}/{n}.json  번역본별 책 단위 본문 (7종 × 66권)
sw.js               오프라인 캐시 (PWA)
convert.py          원본 SQLite → JSON 변환 스크립트 (재실행용)
```
